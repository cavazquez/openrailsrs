# Numeric brake and power fixtures

These are parameter-only exports from the original installed Chiltern and Demo Model 1 formations. They preserve vehicle order and select the author's OpenRails overrides. Bristol and Birmingham Pullman reference the same eight vehicle files.

`profiles.json` records the original relative names and exported fields; `provenance.json` records source SHA-256 values. No original shapes, textures, cab images, sounds or C# script code are included. The script names are declarations only.

The pinned OR 1.6.1 helper consumes these profiles for subsystem experiments. These files are not complete redistributions or a substitute for the original installation. Their hashes and consist hashes are frozen in `oracles/openrails-reference.toml`.
