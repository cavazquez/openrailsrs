# Ejecución dirigida de la versión integrada

Se publican los resultados reales del batch y del build indicados por sus hashes. Pasaron LIRR completo, el ciclo de vapor acotado, Chiltern histórico, cuatro ensayos cortos, Class47 y tres paradas jugables. Cada medición conserva su recibo y su resultado. Las referencias y los pases anteriores permanecen intactos.

Este pase dirigido no sustituye la ejecución completa de check.sh ni autoriza cierres. El ciclo nativo de vapor conserva conservation_passed=null; los balances del modelo propio se prueban aparte. No se incluyen modelos, rutas originales, DLL, credenciales ni las seis trazas humanas. Los recibos/logs son literales y conservan rutas del equipo como procedencia. Los CSV opcionales están comprimidos sin pérdida, con hashes del original y del gzip.
